1 📌 Introdução

O controle tecnológico do concreto é fundamental para garantir a qualidade e o desempenho das estruturas de concreto armado. Conforme a ABNT NBR 12655 (ABNT, 2015), esse controle envolve o acompanhamento das propriedades do concreto e a verificação de sua conformidade com os requisitos estabelecidos. Nesse contexto, a análise estatística dos resultados de ensaios e registros de campo constitui uma importante ferramenta para avaliar o comportamento do material e subsidiar decisões técnicas.

A confiabilidade dessas análises, entretanto, depende diretamente da qualidade dos dados utilizados. Bases provenientes de diferentes fontes podem apresentar valores ausentes, erros de digitação, inconsistências na representação numérica, categorias não padronizadas e classificação inadequada das variáveis. O tratamento dessas inconsistências é, portanto, uma etapa essencial antes da realização das análises estatísticas.

Neste trabalho, é analisada uma base de dados de controle tecnológico do concreto, composta por 100 observações e 10 variáveis, contendo informações relacionadas às propriedades e ao desempenho do material. A base apresenta inconsistências intencionalmente inseridas, como erros de digitação, separadores decimais inadequados, categorias despadronizadas, valores ausentes e variáveis quantitativas classificadas como texto.

Para o processamento dos dados, utiliza-se a linguagem R, com ênfase nos recursos do Base R, abrangendo as etapas de inspeção, diagnóstico, limpeza, padronização e análise exploratória. Ao final, são obtidas estatísticas descritivas e criadas variáveis derivadas, permitindo avaliar o comportamento dos dados e gerar informações relevantes para o controle tecnológico e a tomada de decisões na Engenharia Civil.

2 🎯 Objetivos

Processar, limpar e analisar uma base de dados de controle tecnológico do concreto utilizando a linguagem R, identificando e tratando inconsistências e obtendo informações que contribuam para a avaliação do desempenho do material e para a tomada de decisões técnicas.

2.2 Objetivos específicos

  • Inspecionar a estrutura e as características da base de dados;
  • Identificar valores ausentes, erros de registro e inconsistências;
  • Padronizar e tratar as variáveis para a realização das análises;
  • Aplicar recursos do Base R na manipulação e exploração dos dados;
  • Calcular estatísticas descritivas e comparar diferentes grupos de dados;
  • Criar variáveis derivadas relacionadas ao desempenho do concreto;
  • Interpretar os resultados considerando sua aplicação na Engenharia Civil;
  • Documentar os procedimentos realizados, garantindo maior organização e reprodutibilidade da análise

3 📚 Fundamentação Teórica

3.1 Análise e qualidade dos dados

A análise estatística de dados deve ser precedida por uma etapa de inspeção e verificação da qualidade das informações. A presença de valores ausentes, erros de digitação, categorias inconsistentes ou registros incompatíveis com o fenômeno estudado pode comprometer os resultados obtidos e conduzir a interpretações equivocadas.

Nesse contexto, a preparação dos dados compreende procedimentos de identificação, organização, correção e padronização das informações. A utilização de ferramentas computacionais, como o ambiente R, possibilita automatizar parte dessas etapas e permite maior rastreabilidade dos procedimentos realizados.

A inspeção inicial da estrutura dos dados é necessária para verificar a quantidade de observações e variáveis, além dos tipos atribuídos pelo software. Essa etapa permite identificar se as variáveis foram importadas corretamente e se sua natureza está de acordo com o significado que possuem no estudo.

3.2 Variáveis quantitativas e qualitativas

As variáveis podem ser classificadas de acordo com a natureza da informação que representam. Variáveis quantitativas são aquelas expressas numericamente e associadas a medidas ou contagens, enquanto variáveis qualitativas representam categorias ou atributos.

No contexto do controle tecnológico do concreto, resistência à compressão, consumo de cimento, abatimento, densidade, absorção, idade e relação água/cimento são exemplos de variáveis quantitativas. Já informações como bloco da obra e tipo de concreto são variáveis qualitativas, pois representam categorias.

A correta classificação das variáveis é fundamental para a análise estatística, uma vez que diferentes tipos de dados requerem diferentes operações. Uma variável quantitativa armazenada incorretamente como texto, por exemplo, pode impedir cálculos de média, variância e outras medidas estatísticas.

3.3 Valores ausentes e tratamento dos dados

Valores ausentes são informações não disponíveis em determinadas observações e podem ocorrer por diferentes motivos, como falha na coleta, ausência de medição, erro de registro ou indisponibilidade da informação original.

A identificação dos valores ausentes deve ser realizada antes da análise estatística. Entretanto, a simples presença de um valor ausente não justifica sua substituição automática ou a exclusão da observação. O procedimento adotado deve considerar a origem da ausência, a quantidade de dados afetados e o objetivo da análise.

Entre as possibilidades de tratamento estão a consulta à fonte original, a manutenção do valor como NA, a exclusão da observação ou a utilização de métodos de imputação. A escolha deve ser tecnicamente justificada, uma vez que alterações inadequadas podem introduzir vieses e modificar a distribuição dos dados.

3.4 Padronização e consistência das categorias

Em bases de dados com variáveis qualitativas, a padronização das categorias é essencial. Pequenas diferenças de grafia podem fazer com que o software interprete registros equivalentes como categorias distintas.

Por exemplo, as categorias C30, c30 e C-30 podem ser interpretadas computacionalmente como três grupos diferentes, embora possam representar a mesma classe de concreto. O mesmo problema pode ocorrer com a identificação dos blocos de uma obra.

A padronização evita a fragmentação artificial dos grupos e garante que operações de agrupamento, contagem e cálculo de médias sejam realizadas corretamente.

3.5 Estatística descritiva

A estatística descritiva compreende métodos destinados à organização, síntese e apresentação dos dados. Entre as principais medidas utilizadas estão as medidas de tendência central e de dispersão.

No controle tecnológico do concreto, a resistência média permite representar o comportamento central de determinado conjunto de resultados. Entretanto, a média isoladamente não descreve a variabilidade dos resultados, sendo necessário considerar também medidas de dispersão.

O desvio padrão é uma medida que quantifica a dispersão dos valores em relação à média. Quanto maior o desvio padrão, maior tende a ser a variabilidade dos resultados.

O coeficiente de variação relaciona o desvio padrão à média. Essa medida permite avaliar a variabilidade relativa dos resultados e facilita a comparação entre grupos que apresentam diferentes magnitudes de média.

Os valores mínimo e máximo também são úteis para caracterizar a amplitude dos resultados e identificar observações que possam necessitar de investigação.

3.6 Análise de dados agrupados

A análise agrupada consiste em comparar uma determinada variável entre diferentes categorias ou grupos. No presente estudo, a resistência à compressão pode ser analisada segundo o bloco da obra, o tipo de concreto e a idade dos corpos de prova.

A comparação das médias permite identificar diferenças descritivas entre os grupos. Entretanto, uma diferença entre médias não implica necessariamente uma diferença estatisticamente significativa. Para conclusões de natureza inferencial, seriam necessários testes estatísticos apropriados.

Dessa forma, os resultados obtidos nesta etapa devem ser interpretados como uma descrição do comportamento observado na base de dados.

3.7 Resistência à compressão do concreto

A resistência à compressão é uma das principais propriedades utilizadas na caracterização do concreto endurecido e no controle tecnológico. Seu valor está relacionado à capacidade do material de suportar esforços de compressão e é influenciado por diferentes fatores associados à composição e às condições de produção e cura.

A análise da resistência deve considerar características como a classe do concreto, a relação água/cimento, o consumo de cimento e a idade do corpo de prova. Portanto, a comparação entre resultados de resistência deve ser realizada considerando as condições nas quais os corpos de prova foram produzidos e ensaiados.

3.8 Relação água/cimento e resistência

A relação água/cimento constitui uma variável de grande importância para o comportamento do concreto. Em condições comparáveis, o aumento da quantidade de água em relação ao material cimentante tende a aumentar a porosidade da pasta após o endurecimento, podendo resultar em redução da resistência mecânica.

Assim, a relação água/cimento e a resistência à compressão devem ser analisadas conjuntamente. Entretanto, outros fatores também interferem no comportamento observado, como tipo e características dos materiais, consumo de cimento, condições de cura, idade e procedimentos de produção.

Dessa maneira, uma eventual tendência identificada nos dados deve ser interpretada como uma associação observada no conjunto analisado, não necessariamente como uma relação causal isolada.

3.9 Consumo de cimento e resistência

O consumo de cimento também constitui uma variável relevante na análise do concreto. Entretanto, a relação entre consumo de cimento e resistência não deve ser interpretada isoladamente.

Um maior consumo de cimento pode estar associado a diferentes características de dosagem e desempenho, mas a resistência depende da interação entre diversos fatores, especialmente da relação água/cimento, das características dos agregados, da compactação e das condições de cura.

Por essa razão, a investigação da afirmação de que maiores consumos de cimento resultam em maiores resistências deve considerar conjuntamente as variáveis disponíveis na base.

3.10 Influência da idade na resistência

A resistência do concreto apresenta evolução ao longo do tempo devido ao processo de hidratação do cimento. Em condições adequadas de cura, a hidratação promove transformações na microestrutura da pasta cimentícia, contribuindo para o desenvolvimento progressivo da resistência.

Consequentemente, corpos de prova submetidos ao ensaio em diferentes idades podem apresentar valores de resistência distintos. A idade deve, portanto, ser considerada na interpretação e comparação dos resultados de resistência à compressão.

3.11 Utilização do R na análise estatística

O R é uma linguagem e ambiente computacional voltado à análise estatística, manipulação e visualização de dados. Entre suas características está a possibilidade de realizar operações vetorizadas e utilizar funções específicas para diferentes etapas do processamento dos dados.

Funções como str(), summary(), aggregate(), split(), lapply(), sapply() e apply() permitem realizar diferentes operações de inspeção, agrupamento e processamento.

A utilização de estruturas de programação, como for e if, também permite desenvolver procedimentos iterativos e condicionais. Entretanto, quando uma operação pode ser realizada diretamente sobre vetores, a abordagem vetorizada geralmente proporciona códigos mais concisos e adequados à lógica de funcionamento do R.

4 ⚙️ Metodologia

4.1 Importação e reconhecimento da base

Inicialmente, a base de dados foi importada para o ambiente R e atribuída ao objeto dados.

A importação foi realizada utilizando a função read.csv():

dados <- read.csv("nome_do_arquivo.csv")

Após a importação, foram utilizadas as funções head(), dim() e names():

head(dados)
dim(dados)
names(dados)

A função head() permitiu visualizar as primeiras observações, dim() permitiu verificar o número de linhas e colunas e names() apresentou os nomes das variáveis.

4.2 Verificação da estrutura da base

A estrutura da base foi analisada utilizando a função str():

str(dados)

Essa função permitiu verificar o número de observações, o número de variáveis e os tipos de dados reconhecidos pelo R.

Também foi utilizado o comando:

summary(dados)

para obter um resumo das variáveis.

4.3 Verificação dos valores ausentes

A existência de valores ausentes foi investigada utilizando:

sum(is.na(dados))

A quantidade de valores ausentes por variável foi obtida com:

colSums(is.na(dados))

Para localizar as posições dos valores ausentes, foi utilizado:

which(is.na(dados), arr.ind = TRUE)

4.4 Investigação de valores potencialmente problemáticos

Foram verificadas as variáveis relacionadas à idade, resistência, abatimento, densidade, relação água/cimento e absorção.

Exemplos de códigos utilizados:

dados[dados$idade <= 0, ]

dados[dados$resistencia <= 0, ]

dados[dados$abatimento < 0, ]

dados[dados$densidade <= 0, ]

dados[dados$relacao_a_c < 0, ]

dados[dados$absorcao < 0, ]

Esses comandos permitem localizar registros que apresentam valores incompatíveis com os critérios definidos para a análise.

Também foram verificadas as categorias das variáveis qualitativas:

unique(dados$obra)
table(dados$obra)

unique(dados$tipo_concreto)
table(dados$tipo_concreto)

4.5 Criação da base limpa

Para preservar a base original, foi criada uma cópia denominada dados_limpos:

dados_limpos <- dados

As alterações necessárias foram realizadas somente no objeto dados_limpos.

Após as correções, a estrutura foi novamente verificada:

str(dados_limpos)
summary(dados_limpos)

4.6 Correção dos tipos das variáveis

As variáveis quantitativas foram verificadas por meio da função str().

Quando necessário, foram convertidas para o formato numérico utilizando as.numeric():

dados_limpos$resistencia <- as.numeric(dados_limpos$resistencia`

Após a conversão, a estrutura foi novamente verificada:

str(dados_limpos)`

4.7 Análise da resistência média

A resistência média geral foi calculada utilizando mean():

mean(dados_limpos$resistencia, na.rm = TRUE)

O argumento na.rm = TRUE permite que os valores “NA” sejam desconsiderados no cálculo.

A resistência média por obra foi calculada utilizando aggregate():

aggregate(`
  resistencia ~ obra,
  data = dados_limpos,
  FUN = mean,
  na.rm = TRUE
)

A resistência média por tipo de concreto foi obtida por:

aggregate(
  resistencia ~ tipo_concreto,
  data = dados_limpos,
  FUN = mean,
  na.rm = TRUE
)

E a resistência média por idade:

aggregate(
  resistencia ~ idade,
  data = dados_limpos,
  FUN = mean,
  na.rm = TRUE
)

4.8 Utilização de aggregate()

Para calcular simultaneamente as médias das propriedades do concreto por tipo, foi utilizado:

aggregate(
  cbind(
    resistencia,
    consumo_cimento,
    relacao_a_c,
    abatimento,
    densidade
  ) ~ (tipo_concreto,
  data = dados_limpos,
  FUN = mean,
  na.rm = TRUE
)
)

Essa operação permitiu comparar as características médias das diferentes classes de concreto.

4.9 Criação da variável resistencia_relativa

Foi criada a variável resistencia_ref, contendo os valores de referência de acordo com a classe do concreto.

Em seguida, foi criada a variável resistencia_relativa:

dados_limpos$resistencia_relativa <-
  dados_limpos$resistencia /
  dados_limpos$resistencia_ref

A variável representa a razão entre a resistência observada e a resistência de referência.

Valores superiores a 1 indicam resistência observada superior à referência, enquanto valores inferiores a 1 indicam resistência inferior à referência.

4.10 Criação da variável classificacao:

Foi criada uma variável denominada classificacao para classificar os corpos de prova de acordo com os critérios estabelecidos para a análise.

Os critérios utilizados foram definidos previamente e aplicados por meio de estruturas condicionais do R.

4.11 Criação da variável acima_media:

A variável acima_media foi criada para indicar se a resistência de cada corpo de prova estava acima ou abaixo da média de seu respectivo tipo de concreto.

Essa variável foi definida como lógica, assumindo os valores TRUE ou FALSE.

4.12 Utilização de split():

A base foi dividida de acordo com tipo_concreto utilizando:

grupos_concreto <- split(
  dados_limpos,
  dados_limpos$tipo_concreto
)

A quantidade de observações em cada grupo foi obtida utilizando:

sapply(grupos_concreto, nrow)

4.13 Utilização de lapply() e sapply():

A resistência média de cada grupo foi calculada utilizando lapply():

medias_lapply <- lapply(
  grupos_concreto,
  function(x) {
    mean(x$resistencia, na.rm = TRUE)
 }
)

Posteriormente, a mesma operação foi realizada com sapply():

medias_sapply <- sapply(
  grupos_concreto,
  function(x) {
    mean(x$resistencia, na.rm = TRUE)
 }
)

A principal diferença é que lapply() retorna uma lista, enquanto sapply() procura simplificar o resultado.

4.14 Utilização de apply():

As variáveis quantitativas foram selecionadas:

quantitativas <- dados_limpos[
  ,
  c(
    "resistencia",

    "relacao_a_c"`

  )
]

A média de cada variável foi calculada utilizando:

apply(

Também foi calculada uma medida resumo para cada observação:

apply(

Nesse segundo caso, deve-se destacar que a média obtida entre variáveis com diferentes unidades e significados físicos não possui necessariamente uma interpretação física direta.

4.15 Utilização de for e if:

Para identificar os corpos de prova cuja resistência estivesse acima da média de sua classe, foi utilizada uma estrutura for combinada com if:

 for (i in 1:nrow(dados_limpos)) { 

  classe <- dados_limpos$tipo_concreto[i]

  media_classe <- mean(
    dados_limpos$resistencia[
      dados_limpos$tipo_concreto == classe
    ],
    na.rm = TRUE
  )

  if (dados_limpos$resistencia[i] > media_classe) {

    print(dados_limpos[i, ])

  }
}

A mesma análise foi posteriormente realizada por meio de uma abordagem vetorizada.

A comparação entre as duas soluções considerou simplicidade, legibilidade e eficiência.

## 📌 Introdução

O controle tecnológico do concreto é fundamental para garantir a qualidade e o desempenho das estruturas de concreto armado. Conforme a ABNT NBR 12655 (ABNT, 2015), esse controle envolve o acompanhamento das propriedades do concreto e a verificação de sua conformidade com os requisitos estabelecidos. Nesse contexto, a análise estatística dos resultados de ensaios e registros de campo constitui uma importante ferramenta para avaliar o comportamento do material e subsidiar decisões técnicas.

A confiabilidade dessas análises, entretanto, depende diretamente da qualidade dos dados utilizados. Bases provenientes de diferentes fontes podem apresentar valores ausentes, erros de digitação, inconsistências na representação numérica, categorias não padronizadas e classificação inadequada das variáveis. O tratamento dessas inconsistências é, portanto, uma etapa essencial antes da realização das análises estatísticas.

Neste trabalho, é analisada uma base de dados de controle tecnológico do concreto, composta por 100 observações e 10 variáveis, contendo informações relacionadas às propriedades e ao desempenho do material. A base apresenta inconsistências intencionalmente inseridas, como erros de digitação, separadores decimais inadequados, categorias despadronizadas, valores ausentes e variáveis quantitativas classificadas como texto.

Para o processamento dos dados, utiliza-se a linguagem R, com ênfase nos recursos do Base R, abrangendo as etapas de inspeção, diagnóstico, limpeza, padronização e análise exploratória. Ao final, são obtidas estatísticas descritivas e criadas variáveis derivadas, permitindo avaliar o comportamento dos dados e gerar informações relevantes para o controle tecnológico e a tomada de decisões na Engenharia Civil.

## 📚  Fundamentação Teórica

### Análise e qualidade dos dados

A análise estatística de dados deve ser precedida por uma etapa de inspeção e verificação da qualidade das informações. A presença de valores ausentes, erros de digitação, categorias inconsistentes ou registros incompatíveis com o fenômeno estudado pode comprometer os resultados obtidos e conduzir a interpretações equivocadas.

Nesse contexto, a preparação dos dados compreende procedimentos de identificação, organização, correção e padronização das informações. A utilização de ferramentas computacionais, como o ambiente R, possibilita automatizar parte dessas etapas e permite maior rastreabilidade dos procedimentos realizados.

A inspeção inicial da estrutura dos dados é necessária para verificar a quantidade de observações e variáveis, além dos tipos atribuídos pelo software. Essa etapa permite identificar se as variáveis foram importadas corretamente e se sua natureza está de acordo com o significado que possuem no estudo.

### Variáveis quantitativas e qualitativas

As variáveis podem ser classificadas de acordo com a natureza da informação que representam. Variáveis quantitativas são aquelas expressas numericamente e associadas a medidas ou contagens, enquanto variáveis qualitativas representam categorias ou atributos.

No contexto do controle tecnológico do concreto, resistência à compressão, consumo de cimento, abatimento, densidade, absorção, idade e relação água/cimento são exemplos de variáveis quantitativas. Já informações como bloco da obra e tipo de concreto são variáveis qualitativas, pois representam categorias.

A correta classificação das variáveis é fundamental para a análise estatística, uma vez que diferentes tipos de dados requerem diferentes operações. Uma variável quantitativa armazenada incorretamente como texto, por exemplo, pode impedir cálculos de média, variância e outras medidas estatísticas.

### Valores ausentes e tratamento dos dados

Valores ausentes são informações não disponíveis em determinadas observações e podem ocorrer por diferentes motivos, como falha na coleta, ausência de medição, erro de registro ou indisponibilidade da informação original.

A identificação dos valores ausentes deve ser realizada antes da análise estatística. Entretanto, a simples presença de um valor ausente não justifica sua substituição automática ou a exclusão da observação. O procedimento adotado deve considerar a origem da ausência, a quantidade de dados afetados e o objetivo da análise.

Entre as possibilidades de tratamento estão a consulta à fonte original, a manutenção do valor como NA, a exclusão da observação ou a utilização de métodos de imputação. A escolha deve ser tecnicamente justificada, uma vez que alterações inadequadas podem introduzir vieses e modificar a distribuição dos dados.

### Padronização e consistência das categorias

Em bases de dados com variáveis qualitativas, a padronização das categorias é essencial. Pequenas diferenças de grafia podem fazer com que o software interprete registros equivalentes como categorias distintas.

Por exemplo, as categorias `C30`, `c30` e `C-30` podem ser interpretadas computacionalmente como três grupos diferentes, embora possam representar a mesma classe de concreto. O mesmo problema pode ocorrer com a identificação dos blocos de uma obra.

A padronização evita a fragmentação artificial dos grupos e garante que operações de agrupamento, contagem e cálculo de médias sejam realizadas corretamente.

### Estatística descritiva

A estatística descritiva compreende métodos destinados à organização, síntese e apresentação dos dados. Entre as principais medidas utilizadas estão as medidas de tendência central e de dispersão.

No controle tecnológico do concreto, a resistência média permite representar o comportamento central de determinado conjunto de resultados. Entretanto, a média isoladamente não descreve a variabilidade dos resultados, sendo necessário considerar também medidas de dispersão.

O desvio padrão é uma medida que quantifica a dispersão dos valores em relação à média. Quanto maior o desvio padrão, maior tende a ser a variabilidade dos resultados.

O coeficiente de variação relaciona o desvio padrão à média. Essa medida permite avaliar a variabilidade relativa dos resultados e facilita a comparação entre grupos que apresentam diferentes magnitudes de média.

Os valores mínimo e máximo também são úteis para caracterizar a amplitude dos resultados e identificar observações que possam necessitar de investigação.

### Análise de dados agrupados

A análise agrupada consiste em comparar uma determinada variável entre diferentes categorias ou grupos. No presente estudo, a resistência à compressão pode ser analisada segundo o bloco da obra, o tipo de concreto e a idade dos corpos de prova.

A comparação das médias permite identificar diferenças descritivas entre os grupos. Entretanto, uma diferença entre médias não implica necessariamente uma diferença estatisticamente significativa. Para conclusões de natureza inferencial, seriam necessários testes estatísticos apropriados.

Dessa forma, os resultados obtidos nesta etapa devem ser interpretados como uma descrição do comportamento observado na base de dados.

### Resistência à compressão do concreto

A resistência à compressão é uma das principais propriedades utilizadas na caracterização do concreto endurecido e no controle tecnológico. Seu valor está relacionado à capacidade do material de suportar esforços de compressão e é influenciado por diferentes fatores associados à composição e às condições de produção e cura.

A análise da resistência deve considerar características como a classe do concreto, a relação água/cimento, o consumo de cimento e a idade do corpo de prova. Portanto, a comparação entre resultados de resistência deve ser realizada considerando as condições nas quais os corpos de prova foram produzidos e ensaiados.

### Relação água/cimento e resistência

A relação água/cimento constitui uma variável de grande importância para o comportamento do concreto. Em condições comparáveis, o aumento da quantidade de água em relação ao material cimentante tende a aumentar a porosidade da pasta após o endurecimento, podendo resultar em redução da resistência mecânica.

Assim, a relação água/cimento e a resistência à compressão devem ser analisadas conjuntamente. Entretanto, outros fatores também interferem no comportamento observado, como tipo e características dos materiais, consumo de cimento, condições de cura, idade e procedimentos de produção.

Dessa maneira, uma eventual tendência identificada nos dados deve ser interpretada como uma associação observada no conjunto analisado, não necessariamente como uma relação causal isolada.

### Consumo de cimento e resistência

O consumo de cimento também constitui uma variável relevante na análise do concreto. Entretanto, a relação entre consumo de cimento e resistência não deve ser interpretada isoladamente.

Um maior consumo de cimento pode estar associado a diferentes características de dosagem e desempenho, mas a resistência depende da interação entre diversos fatores, especialmente da relação água/cimento, das características dos agregados, da compactação e das condições de cura.

Por essa razão, a investigação da afirmação de que maiores consumos de cimento resultam em maiores resistências deve considerar conjuntamente as variáveis disponíveis na base.

### Influência da idade na resistência

A resistência do concreto apresenta evolução ao longo do tempo devido ao processo de hidratação do cimento. Em condições adequadas de cura, a hidratação promove transformações na microestrutura da pasta cimentícia, contribuindo para o desenvolvimento progressivo da resistência.

Consequentemente, corpos de prova submetidos ao ensaio em diferentes idades podem apresentar valores de resistência distintos. A idade deve, portanto, ser considerada na interpretação e comparação dos resultados de resistência à compressão.

### Utilização do R na análise estatística

O R é uma linguagem e ambiente computacional voltado à análise estatística, manipulação e visualização de dados. Entre suas características está a possibilidade de realizar operações vetorizadas e utilizar funções específicas para diferentes etapas do processamento dos dados.

Funções como `str()`, `summary()`, `aggregate()`, `split()`, `lapply()`, `sapply()` e `apply()` permitem realizar diferentes operações de inspeção, agrupamento e processamento.

A utilização de estruturas de programação, como for e if, também permite desenvolver procedimentos iterativos e condicionais. Entretanto, quando uma operação pode ser realizada diretamente sobre vetores, a abordagem vetorizada geralmente proporciona códigos mais concisos e adequados à lógica de funcionamento do `R`.

### Análise da resistência média

A resistência média geral foi calculada utilizando `mean()`:
```
mean(dados_limpos$resistencia, na.rm = TRUE)
```
O argumento `na.rm = TRUE` permite que os valores "NA" sejam desconsiderados no cálculo.

A resistência média por obra foi calculada utilizando `aggregate()`:
```
aggregate(`
  resistencia ~ obra,
  data = dados_limpos,
  FUN = mean,
  na.rm = TRUE
)
```
A resistência média por tipo de concreto foi obtida por:

E a resistência média por idade:
```
aggregate(
  resistencia ~ idade,
  data = dados_limpos,
  FUN = mean,
  na.rm = TRUE
)
```

### Criação da variável `resistencia_relativa`

Foi criada a variável `resistencia_ref`, contendo os valores de referência de acordo com a classe do concreto.

```
dados_limpos$resistencia_relativa <-
```

### Utilização de `for` e `if`:

Para identificar os corpos de prova cuja resistência estivesse acima da média de sua classe, foi utilizada uma estrutura `for` combinada com `if`:
```
 for (i in 1:nrow(dados_limpos)) { 

  classe <- dados_limpos$tipo_concreto[i]

  media_classe <- mean(
    dados_limpos$resistencia[
      dados_limpos$tipo_concreto == classe
    ],
    na.rm = TRUE
  )

  if (dados_limpos$resistencia[i] > media_classe) {

    print(dados_limpos[i, ])

  }
}
```
A mesma análise foi posteriormente realizada por meio de uma abordagem vetorizada.

A comparação entre as duas soluções considerou simplicidade, legibilidade e eficiência.
